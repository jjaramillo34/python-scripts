Filters that matter

Size, color, type, layout, license, time range, and region.

Header-only auth

Send X-API-Key. Query-string keys are rejected.

Rate limited

30 searches per minute per IP, plus a failed-auth cap.

Useful payloads

URL, thumbnail, title, source site, and dimensions.

Search parameters

Name Required Notes
queryYesSearch keywords
max_resultsNo1–100, default 10

Quick start

Examples

curl -H "X-API-Key: YOUR_API_KEY" \
  "{{ base_url }}/api/search?query=butterfly&max_results=5"
curl -X POST "{{ base_url }}/api/search" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "butterfly", "max_results": 5}'
fetch('{{ base_url }}/api/search?query=butterfly&max_results=5', {
  headers: {
    'X-API-Key': 'YOUR_API_KEY'
  }
})
