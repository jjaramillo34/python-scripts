Search images and news with a locked-down REST API.

Query DuckDuckGo images and news, with filters for size, color, type, layout, license, region, and time. Pass a US street address and results are narrowed to ones that actually mention it. Search calls need a valid API key in the header — not in the URL.

Try a search {% if docs_enabled %} Open API docs {% endif %} Copy a curl

Precise addresses

Send address. The street line is quoted and off-target results are dropped.

News search

Bing, DuckDuckGo, and Yahoo news with automatic fallback and ISO dates.

Filters that matter

Size, color, type, layout, license, time range, and region.

Header-only auth

Send X-API-Key. Query-string keys are rejected.

Rate limited

30 searches per minute per IP across images and news, plus a failed-auth cap.

Useful payloads

Image URLs and dimensions, article dates and sources, plus the exact query sent upstream.

Authentication

Every /api/search and /api/news call needs a key

Put the key in X-API-Key. The homepage and /health stay public. Ask javier@privatediningpros.com if you need access.

Reference

Endpoints

GET /api/search

Search images with query parameters. Requires X-API-Key.

POST /api/search

Same image search, JSON body. Requires X-API-Key.

GET /api/news

Search news with query parameters. Requires X-API-Key.

POST /api/news

Same news search, JSON body. Requires X-API-Key.

GET /health

Public liveness check for load balancers.

GET /api/info

Public JSON summary of endpoints and example calls.

Search parameters

Name Required Notes
queryOne of query / addressSearch keywords. Quote words to require that exact phrase.
addressOne of query / addressUS street address, e.g. 265 South Street Manhattan NY 10004. Sent upstream as "265 South Street" Manhattan NY.
strictNoDrop results that don't mention the address or quoted phrases. On by default with address.
max_resultsNo1–100, default 10
regionNous-en, uk-en, wt-wt
safesearchNooff, moderate, on
timelimitNod, w, m, y
backendNoImages: auto, bing, duckduckgo. News adds yahoo.
sizeNoImages only. Small, Medium, Large, Wallpaper
color / type_image / layout / license_imageNoImages only. Visual filters (these use the DuckDuckGo backend)
validate_imagesNoImages only. Check that image URLs are reachable

Quick start

Examples

curl -H "X-API-Key: YOUR_API_KEY" \
  "{{ base_url }}/api/search?query=butterfly&max_results=5"
curl -X POST "{{ base_url }}/api/search" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "butterfly", "max_results": 5}'
curl -H "X-API-Key: YOUR_API_KEY" \
  "{{ base_url }}/api/news?query=sun&timelimit=m&max_results=5"
curl -G -H "X-API-Key: YOUR_API_KEY" "{{ base_url }}/api/search" \
  --data-urlencode "address=265 South Street Manhattan NY 10004"

curl -G -H "X-API-Key: YOUR_API_KEY" "{{ base_url }}/api/news" \
  --data-urlencode "address=265 South Street Manhattan NY 10004" \
  --data-urlencode "query=construction"
fetch('{{ base_url }}/api/search?query=butterfly&max_results=5', {
  headers: {
    'X-API-Key': 'YOUR_API_KEY'
  }
})

Responses
